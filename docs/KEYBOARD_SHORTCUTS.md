# Scribe - Keyboard Shortcuts

**Quick reference for all keyboard shortcuts**

---

## File Operations

| Shortcut | Action |
|----------|--------|
| ⌘N | **New Note** - Create a new blank note |
| ⌘D | **Daily Note** - Open or create today's daily note |
| ⌘⇧C | **Quick Capture** - Open quick capture window |
| ⌘W | **Close Tab** - Close current note tab |
| ⌘S | Auto-save (happens automatically) |

---

## View & Navigation

| Shortcut | Action |
|----------|--------|
| ⌘B | **Toggle Left Sidebar** - Show/hide project navigation |
| ⌘P | **Toggle Preview** - Show/hide markdown preview |
| ⌘⌥R | **Toggle Right Sidebar** - Show/hide backlinks/tags/properties |
| ⌘⌥→ | **Next Tab** - Switch to next open note |
| ⌘⌥← | **Previous Tab** - Switch to previous open note |

---

## Formatting (in editor)

| Shortcut | Action | Markdown |
|----------|--------|----------|
| ⌘B | **Bold** | `**text**` |
| ⌘I | **Italic** | `*text*` |
| ⌘E | **Code** | `` `code` `` |
| ⌘K | **Link** | `[text](url)` |

## Special Input

| Syntax | Result |
|--------|--------|
| `# Heading` | Heading 1 |
| `## Heading` | Heading 2 |
| `### Heading` | Heading 3 |
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `` `code` `` | `code` |
| `[[Note Title]]` | Wiki link to note |
| `#tag` | Tag |
| `$E=mc^2$` | Inline math |
| `$$...$$` | Display math block |

## Tips

### ADHD-Optimized Workflow

1. **⌘⇧C** - Quick capture for fleeting thoughts
2. **⌘D** - Daily note for journaling
3. **⌘N** - New note for deeper work
4. **⌘P** - Toggle preview to focus on writing
5. **⌘B** - Hide sidebar to minimize distractions

### Knowledge Building

1. Use **[[wiki links]]** to connect ideas
2. Check **backlinks panel** (⌘⌥R) to see connections
3. Add **#tags** for categorization
4. Use **projects** for organization

### Research Writing

1. Write in **markdown** (left pane)
2. See **live preview** (right pane)
3. Add **math** with `$...$` or `$$...$$`
4. Link to **literature notes** with `[[...]]`
5. Track **citations** with tags (citations feature coming)
